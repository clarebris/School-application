# 🌾 Smart-Farmers

Smart-Farmers is a React-based web app that sends SMS alerts to farmers in their preferred local language, with region-based targeting and an admin dashboard for managing alerts.

## 🚀 Features

- 🌍 Region-based farmer targeting
- 🗣️ Multi-language SMS alerts
- 🔐 Admin dashboard with protected routes
- 📱 Mobile-friendly UI with Tailwind CSS
- 🔄 Social login integration (Google, Facebook)
- 👁️ Password visibility toggle and validation

## 🛠️ Tech Stack

- **React** + **Vite** for fast development
- **Tailwind CSS** for responsive styling
- **React Router** for multi-page navigation
- **Firebase** (planned) for authentication and hosting
- **GitHub** for version control
